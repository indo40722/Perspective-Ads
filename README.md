# Perspective Ads

**視点を変えると、広告の奥が見える。**

Perspective Adsは、見る人の位置に合わせて3D広告の見え方が変わる、デジタルサイネージのプロトタイプです。正面では一つのバーガーに見える商品が、左右から覗くと具材ごとにほどけていきます。二つの味を見つけて正面へ戻ると、バーガーが完成し、特典が現れます。

技育展2026に向けて開発中です。広告の中に特典を隠すことで、人が覗いてみたくなるか、商品にも関心を持つか。これはこれから検証する仮説で、効果が実証されたわけではありません。

## 体験の流れ

1. **正面から見る** — 3Dモデルのバーガー広告が一つの形に組み上がっています。
2. **左から覗く** — 炭火焼きパティを見つけます。
3. **右から覗く** — 熟成チェダーを見つけます。
4. **正面へ戻る** — 具材が組み上がり、クーポンとQR画像が表示されます。

特典とQR画像は動作確認用です。実際に利用できるクーポンの配布機能はありません。

## 現在の実装

- WebカメラとMediaPipe Face Meshで1人の顔を検出し、鼻先の左右位置を取得
- 起動時に安定した15フレームの中央値から正面位置を自動設定
- 基準位置からの左右移動だけを追跡し、上下移動は使用しない
- Deadzone、One Euro Filter、時間基準の補間で視点の揺れを抑制
- 新しいカメラフレームのデータだけをSocket.IOで配信
- 視点位置に合わせて非対称視錐台を更新するOff-Axis Projection
- Reactで画面と操作状態を管理し、Three.jsで3D広告を描画
- 画面の縦横比にかかわらず3D表示領域は16:9を維持
- JuzeoneのPBR GLBモデルをThree.jsで読み込み、表示領域に合わせて大きさと中心を自動調整
- GLB内で別オブジェクトの上バンズ・トマト・レタス・チーズ・カツ・下バンズを6層にまとめて分離
- 左右の視点移動で6つの具材層を上下・左右・奥行きへはっきり開き、発見判定に入る時点で最大分離に達する。正面へ戻ると組み上げる
- トマト3枚とゴマは該当する具材層と一緒に動かし、皿・旗・棒は商品表示から除外

## 操作

| キー | 動作 |
| --- | --- |
| `F` | 全画面表示の切り替え |
| `D` | 状態・視点座標の表示切り替え |
| `C` | 正面位置の再調整 |
| `R` | 報酬表示のリセット |
| `D`表示中の`←` / `→` | 左右の発見動作を確認 |
| `D`表示中の`Space` | 正面へ戻る動作を確認 |

## 検証したいことと課題

| 現在の実装 | これから確かめる・改善すること |
| --- | --- |
| 1人の顔を検出し、左右移動に合わせて3D表示 | 複数人がいる場合の対応 |
| Off-Axis Projectionの初期実装 | 画面寸法・カメラ位置・視点距離のキャリブレーション |
| 固定視点距離と概算のカメラ画角 | 実機での表示精度と視点推定 |
| 名前付きの6具材層を持つバーガー3Dモデル | 発見した味と動く具材の対応をさらに明確にする |
| デモ用の特典とQR画像 | 実際のクーポン取得と行動計測 |

MediaPipeのランドマーク座標だけでは実空間の距離を測れないため、現在の視点距離は固定値です。照明や遮蔽、カメラ性能による顔検出の差も残っています。

## 起動方法

### 必要な環境

- Windows
- Python 3.10
- Node.js 20.19以降
- Webカメラ

### 初回起動

リポジトリのフォルダーでPowerShellを開き、Pythonの依存関係をインストールします。

```powershell
py -3.10 -m pip install -r backend/requirements.txt
```

次に起動スクリプトを実行します。フロントエンドの依存関係が未導入ならインストールし、画面をビルドしてからバックエンドを起動します。

```powershell
.\start_backend.bat
```

ブラウザで次のURLを開いてください。

```text
http://localhost:8000/view/index.html
```

### 2回目以降

`start_backend.bat`を実行し、ブラウザを再読み込みします。更新が反映されないときは `Ctrl+F5` を押してください。終了するときは起動したコンソールで `Ctrl+C` を押します。

### 手動で起動する場合

```powershell
npm --prefix frontend install
npm --prefix frontend run build
py -3.10 backend/main.py
```

### カメラが映らないとき

カメラ映像はブラウザではなくPythonバックエンドが取得します。ブラウザのカメラ許可ではなく、Windowsのカメラ設定でデスクトップアプリのアクセスを許可してください。

- `顔を探しています` — カメラ映像を取得できています。顔が画面に入るようにして、正面で少し待ちます。
- `カメラを開けません` — Windowsのカメラ設定を確認し、カメラを使う他のアプリを閉じてからバックエンドを再起動します。

WindowsではDirectShow、Media Foundationの順に接続を試し、カメラが利用可能になるまで再試行します。

## システム構成

```text
Webカメラ
  ↓ 顔の左右位置を取得
OpenCV / MediaPipe Face Mesh
  ↓
Python / FastAPI / Socket.IO（新しい検出データを配信）
  ↓
React / Socket.IO Client
  ↓ 視点・操作状態
Three.js / Off-Axis Projection
  ↓
3D広告ショーケース
```
