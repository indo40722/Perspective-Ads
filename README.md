# Perspective Ads

**視点を変えると、広告の奥が見える。**

Perspective Adsは、見る人の位置に合わせて表示が変わる、デジタルサイネージ広告のプロトタイプです。

正面からは商品に隠れている特典が、少し横へ移動して覗くと見えてきます。画面に触れたり、大きな声を出したりせず、「見る位置を変える」だけで広告に参加できる体験を作っています。

技育展2026に向けて開発中です。現在は、覗き込みによる特典発見を試す段階です。

## 体験の流れ

1. **正面から見る** — 3Dのバーガー広告が表示され、奥の特典は商品に隠れています。
2. **横へ移動する** — 顔の位置に合わせて3D空間の見え方が変わり、商品の後ろにあるクーポンが見えてきます。
3. **特典を見つける** — 一定時間覗くと、報酬とQR画像が画面に表示されます。

※ 現在の特典・QR画像は動作確認用の表示です。実際に店舗で使えるクーポンの配布機能はありません。

## 何を確かめたいのか

街中の広告は、見ている人が一方的に情報を受け取る形式が中心です。

Perspective Adsでは、広告の中に特典を隠すことで、商品への関心とは別に「何かあるかもしれない」と覗いてみるきっかけを作れないかと考えています。

**実際に人が覗いてくれるか、商品にも関心を持つかは、これから検証する仮説です。** 効果が実証されたわけではありません。

## 仕組み

```text
Webカメラ
  ↓ 顔の位置を取得
OpenCV / MediaPipe Face Mesh
  ↓ Socket.IOで座標を送信
JavaScript / Three.js
  ↓ 視点に合わせた投影行列を計算
3D広告（手前の商品と奥の特典）
```

- **顔位置の取得**：Webカメラで1人の顔を検出し、鼻先の位置を基準に座標を求めます。
- **視点連動の表示**：画面サイズと概算の視点位置を使い、Off-Axis Projectionで3D空間を描画します。
- **報酬の発見**：一定以上横へ動いた状態を短時間保つと、特典画面を表示します。

## 現在できていること・これからの課題

| 現在の実装 | これから改善すること |
| --- | --- |
| Webカメラによる1人の顔検出 | 複数人がいる場合の対応 |
| 顔の左右移動に合わせた3D表示 | 視点位置・画面サイズのキャリブレーション |
| Off-Axis Projectionの初期実装 | 実距離の推定と表示精度の改善 |
| DeadzoneとLerpによる基本的な揺れ対策 | 追跡の安定性と遅延の改善 |
| 3Dバーガーと、奥に隠した特典 | 商品表現の改善、実際のクーポン取得 |
| 特典表示とQR画像の表示 | 行動計測と通常広告との比較実験 |

現状は技術検証用の簡易3Dモデルを使用しています。また、Webカメラの画角と視聴距離には概算値・固定値を使っており、実機に合わせた調整は未完成です。

## 起動方法

Python 3.10、Webカメラ、ブラウザを使います。

```bash
# 依存パッケージをインストール
py -3.10 -m pip install -r backend/requirements.txt

# バックエンドを起動
py -3.10 backend/main.py
```

起動後、ブラウザで次のURLを開きます。

```text
http://localhost:8000/view/index.html
```

Windowsでは `start_backend.bat` と `open_frontend.bat` も利用できます。Pythonの起動コマンドが異なる環境では `python` 等に読み替えてください。Three.jsとSocket.IOのJavaScriptライブラリはCDNから読み込むため、初回表示時にはネットワーク接続が必要です。

**操作**：`F` 全画面表示 ／ `D` デバッグ情報 ／ `R` 特典表示をリセット
