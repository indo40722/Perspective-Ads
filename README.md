# Perspective Ads

**広告の前で、一歩動く。見つけた商品情報が、スマートフォンへ続く。**

駅などの公共空間にある縦型デジタルサイネージを想定した試作です。焼き目や断面を探して視点を動かすと、ステーキの皿の奥に隠れたメニュー札が少しずつ現れます。札にあるQRを読むと、スマートフォンで同じ見どころの写真と説明が続きます。

## 体験の流れ

1. 正面で商品写真と広告コピーを見る。
2. 左へ動いて焼き目を見るか、前へ近づいて断面を見る。
3. どちらか一つを約0.9秒見つめると、皿の奥からメニュー札が現れる。札全体が見えるとQRを読み取れる。
4. スマートフォンでQRを読むと、見つけた見どころと同じ写真・説明が表示される。
5. 受取ボタンで一回限りのデモコードを発行する。
6. 店側のデモ画面でコードを一度だけ利用済みにできる。

写真はコンセプト素材です。デモコードは実在の店舗、商品、注文、決済、割引とは連携していません。体験イベントと特典の集計はローカルSQLiteへ保存します。イベントにはランダムIDを使い、個人情報は取得しません。

## 広告管理画面

バックエンドを起動したあと、[http://127.0.0.1:8000/view/admin.html](http://127.0.0.1:8000/view/admin.html)を開きます。

- 広告主ごとのキャンペーンを複数作成・保存し、公開する広告を切り替えられます。
- 全体・見どころ・詳細の3場面に写真を割り当て、PNG・JPEG・WebPを登録できます。3枚そろうまで公開できません。1画像16MB以下、縦横8000px以下、4000万画素以内が条件です。
- 見出し・補足文・動きの案内は、テキストまたは文字組み済み画像で入稿できます。
- 特典の文言、URLから生成するQRまたはQR画像、特典表示確率、背景・アクセント・文字色を設定できます。
- 画面右のプレビューで縦型9:16の見た目を確認し、「保存して公開」を押します。起動中の広告画面は5秒以内に公開内容へ切り替わります。
- 公開した広告をサイネージPCへ保存するには、オンライン中に同じブラウザーで「端末に保存」を押します。公開広告の設定と写真がブラウザー内に保存され、通信が切れてもサイネージ画面を再表示できます。

広告設定はbackend/data/campaigns.sqlite3、アップロード画像はbackend/data/campaign-assets/に保存します。特典表示確率は見どころ発見時の1回ごとの抽選率です。たとえば1%に設定しても、100回で必ず1回当たるわけではありません。同じブラウザータブの再読み込みでは、そのタブの抽選結果を引き継ぎます。

### 広告をオフライン用に保存する

1. PC上でバックエンドを起動し、インターネットにつながっている状態で広告管理画面を開きます。
2. 対象の広告を「保存して公開」したあと、「端末に保存」を押します。未公開の変更がある間は保存できません。
3. 「保存済み」と表示されたら、同じPC・同じブラウザーでサイネージ画面を開きます。以後、インターネットが切れても公開広告と保存済みの写真を表示できます。

保存先はブラウザーとサイトごとです。別のブラウザーや別PCで使う場合は、それぞれでオンライン中に保存してください。`localhost`と`127.0.0.1`、ポート番号が異なるURLも別扱いです。サイトデータを消去すると保存した広告も消えます。QR画像は広告素材として保存されますが、QRの遷移先やクーポンの発行・利用確認には通信が必要です。既定の顔位置追跡では、PC上のバックエンドを起動したままにしてください。オフライン機能は`localhost`・`127.0.0.1`またはHTTPSで動作します。

この管理画面は試作向けで、ログイン認証はありません。インターネットへ公開せず、信頼できるローカル環境で使用してください。QR画像を使う場合は、画像に記録されたリンク先と管理画面のURL欄が一致することを確認してください。

## 起動方法

Windows、Python 3.10、Node.js 20.19以降、Webカメラを使います。初回のみPythonとフロントエンドの依存関係を入れます。

```powershell
py -3.10 -m pip install -r backend/requirements.txt
npm --prefix frontend install
```

プロジェクトフォルダーでPowerShellを開き、バックエンドを起動します。

```powershell
.\start_backend.bat
```

ブラウザーで[http://127.0.0.1:8000/view/index.html](http://127.0.0.1:8000/view/index.html)を開きます。カメラの使用許可を求められたら許可してください。終了時は起動したコンソールで`Ctrl+C`を押します。

### ブラウザー内で顔位置を追跡する

Vercelなどでカメラを接続したPC上のバックエンドを動かせない場合は、フロントエンドをブラウザー追跡モードでビルドします。モデルは顔の位置と大きさだけを読み取り、映像をサーバーへ送信しません。

```powershell
$env:VITE_FACE_TRACKING_SOURCE = "browser"
npm --prefix frontend run build
Remove-Item Env:\VITE_FACE_TRACKING_SOURCE
$env:PERSPECTIVE_CAMERA_ENABLED = "0"
py -3.10 backend/main.py
```

ブラウザーでいつものURLを開き、「カメラを起動」を押して使用するカメラを許可します。カメラが複数ある場合は、画面右上の選択欄から切り替えられます。初回は顔検出の実行ファイルをダウンロードするため、オンラインで一度カメラを起動してください。2回目以降は同じブラウザーでオフライン追跡できます。

Vercel用のビルド設定はリポジトリ直下の`vercel.json`にあります。ただし、現在の管理画面と広告・クーポンAPIはローカルバックエンドを前提としています。Supabaseの会社アカウント、認証、広告データ共有、権限設定は未実装なので、認証を付けるまでは管理画面を外部公開しないでください。

### カメラを使わずに試す

バックエンドを起動するPowerShellで、先にカメラ処理を無効にします。

```powershell
$env:PERSPECTIVE_CAMERA_ENABLED = "0"
py -3.10 backend/main.py
```

その後、同じURLを開きます。画面をドラッグして見どころを移動できます。デバッグ表示中は矢印キーでも操作できます。

### スマートフォンでQRを試す

PCとスマートフォンを同じWi-Fiにつなぎます。`127.0.0.1`はスマートフォン自身を指すため、Windowsで`ipconfig`を実行してPCのIPv4アドレスを確認し、PCとスマートフォンの両方から`http://<PCのIPv4アドレス>:8000/view/`を開きます。ネットワークやファイアウォールの設定によっては接続できない場合があります。

QRを読み取った後、スマートフォンの受取ボタンでデモコードを発行します。店側画面はPCで[http://127.0.0.1:8000/view/redeem.html](http://127.0.0.1:8000/view/redeem.html)を開きます。同じコードは一度しか利用確認できません。

## 検証操作

| 操作 | 動作 |
| --- | --- |
| 顔を左へ動かし、その位置で約0.9秒とどまる | 焼き目を見つけ、皿の奥のメニュー札を引き出す |
| 前へ近づき、その位置で約0.9秒とどまる | 断面を見つけ、皿の奥のメニュー札を引き出す |
| 画面をドラッグ | カメラなしで視点を移動 |
| `D` | 検証パネルを表示 |
| `←` / `→` / `↑` / `↓` / `Space`（検証パネル表示中） | 手動で位置を変える |
| `R` | 広告の進行を最初に戻す |
| `F` | 全画面表示を切り替える |

検証パネルでは、カメラ・顔検出・前進量・見どころの発見・QR表示を確認できます。スライダーを使うとカメラ入力を一時停止して動きを再現できます。

## テストとビルド

```powershell
npm --prefix frontend test
npm --prefix frontend run build
py -3.10 -m unittest discover -s backend -p "test_*.py"
```

## 技術と素材

- ReactとCSSで写真レイヤー、体験進行、特典表示を管理
- 既定ではOpenCV・MediaPipe Face Mesh・FastAPI・Socket.IOで顔位置を取得し、ブラウザー追跡モードではMediaPipe Face DetectorをWeb Worker内で動かす
- ローカルの広告・特典データはSQLiteへ保存。Vercel・Supabaseを使った会社別のクラウド共有は未実装
- SQLiteで見どころ発見・QRページ訪問・受取・利用確認を集計
- 実際の広告へ進む場合は、広告主の許諾を得た商品写真・コピー・特典へ差し替える
