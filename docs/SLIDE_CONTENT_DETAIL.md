# Perspective Ads スライド作成用詳細リスト

**チーム名**: 印藤工房
**発表時間**: 3分

各スライドに記載する文字要素と、デザインの指示をまとめました。

## 1枚目：表紙
- **役割**: タイトル表示、インパクト
- **スライド上の文字**:
    - **Perspective Ads** （大きく）
    その広告は、覗くと動き出す。
    - Team 印藤工房
- **ビジュアル/レイアウト**:
    - 背景：覗き込んでいる人のシルエットと、その先にある「奥行きのある不思議な世界」のイメージ。
    - フォント：ゴシック体（太め）で力強く。

## 2枚目：導入（問いかけ）
- **役割**: 聴衆への問いかけ
- **メインテキスト（中央）**:

- **ビジュアル/レイアウト**:
    - シンプルで静かな背景（黒または暗い単色）。
    - 文字だけを中央に配置し、強く問いかける。左上などには配置しない。

## 3枚目：導入・課題 (Bad Scene)
- **役割**: 厳しい現実の提示
- **メインテキスト（中央）**:
    - 答えは、おそらく**「0」**。
    - 街は情報の墓場になってしまった。
- **ビジュアル/レイアウト**:
    - 背景画像：雑踏の中で、誰も見ていないサイネージや広告の写真（少し暗く落とす、ボカシを入れる）。
    - 数字の「0」を画面中央に非常に大きく配置し、インパクトを出す。

## 7枚目：解決策
- **役割**: ソリューションの提示
- **メインテキスト（中央）**:
    - **「見る」から「覗く」へ。**
    - 受動的な壁を、能動的な動作で壊す。
- **ビジュアル/レイアウト**:
    - 対比図：
        - 左側：従来の広告 = 受動的 (Passive)
        - 右側：Perspective Ads = 能動的 (Active)
    - 「覗く」アクションをする人のピクトグラムやイラストに矢印を添えて動きを表現。

- **ビジュアル/レイアウト**:

    - 「極限同期」などのキーワードを太字で。
